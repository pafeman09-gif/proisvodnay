Базовая математическая теория, необходимая для физики ЕГЭ

В физике производная функции по времени означает скорость протекания процесса или мгновенную скорость изменения величины. Если физическая величина $f$ зависит от времени $t$, то ее мгновенная скорость изменения определяется как предел:

$$f'(t) = \lim_{\Delta t \to 0} \frac{\Delta f}{\Delta t} = \frac{df}{dt}$$

Геометрический смысл производной

Значение производной функции $x(t)$ в точке $t_0$ равно тангенсу угла наклона $\alpha$ касательной, проведённой к графику в этой точке, относительно оси времени:

$$k = \text{tg}\,\alpha = x'(t_0) = v_x(t_0)$$

Таблица базовых производных для физики

Функция $f(t)$ Производная $f'(t)$ Физический пример применения
Константа $C$ $0$ Скорость тела при покое ($x = \text{const} \implies v = 0$).
Степенная: $t^n$ $n \cdot t^{n-1}$ Координата $x(t) = v_0 t + \frac{a t^2}{2} \implies v(t) = v_0 + at$.
Синус: $\sin(\omega t + \varphi_0)$ $\omega \cos(\omega t + \varphi_0)$ Колебания заряда: $q(t) = q_0 \sin(\omega t) \implies I(t) = q_0\omega \cos(\omega t)$.
Косинус: $\cos(\omega t + \varphi_0)$ $-\omega \sin(\omega t + \varphi_0)$ Координата пружинного маятника: $x(t) = A \cos(\omega t) \implies v(t) = -A\omega \sin(\omega t)$.

Условие экстремума: нахождение максимума и минимума

Если требуется найти максимальное или минимальное значение физической величины (например, максимальную мощность, максимальную высоту или критическое сопротивление), необходимо взять первую производную функции по исследуемому параметру и приравнять её к нулю:

$$\frac{df(z)}{dz} = 0 \implies z = z_{\text{extr}}$$

В каких номерах ЕГЭ по физике может встретиться данный метод?

Дифференцирование позволяет избегать заучивания длинных цепочек формул и находить величины напрямую из уравнений движения или процессов.

Замечание эксперта ЕГЭ
В заданиях второй части с развёрнутым ответом использование производной для нахождения скорости, ЭДС индукции или экстремумов функции признаётся абсолютно строгим и корректным решением, не требующим доказательства математических теорем.

Кинематика: Скорость и ускорение

Доказательство: По определению мгновенная скорость — это предел отношения перемещения к малому промежутку времени $\Delta t \to 0$:

$$v_x(t) = \lim_{\Delta t \to 0} \frac{\Delta x}{\Delta t} = x'(t)$$

Аналогично, ускорение есть скорость изменения скорости:

$$a_x(t) = \lim_{\Delta t \to 0} \frac{\Delta v_x}{\Delta t} = v_x'(t) = x''(t)$$

Гармонические колебания (механика и электродинамика)

Пусть координата тела меняется по гармоническому закону: $x(t) = x_{\max} \cos(\omega t)$.

Доказательство связи амплитуд:

  1. Возьмём первую производную по времени для нахождения скорости:
    $$v(t) = x'(t) = (x_{\max} \cos(\omega t))' = -x_{\max} \omega \sin(\omega t)$$
    Коэффициент перед тригонометрической функцией равен амплитудному значению:
    $$v_{\max} = \omega x_{\max}$$
  2. Возьмём производную скорости для нахождения ускорения:
    $$a(t) = v'(t) = (-x_{\max} \omega \sin(\omega t))' = -x_{\max} \omega^2 \cos(\omega t)$$
    Откуда следует связь для амплитуды ускорения:
    $$a_{\max} = \omega^2 x_{\max} = \omega v_{\max}$$
  3. Электромагнитные колебания в LC-контуре: Дифференцируя заряд $q(t) = q_{\max} \cos(\omega t)$, получаем силу тока:
    $$I(t) = q'(t) = -q_{\max} \omega \sin(\omega t) \implies I_{\max} = \omega q_{\max}$$

Электромагнитная индукция: Закон Фарадея

ЭДС индукции в замкнутом проводящем контуре равна скорости изменения магнитного потока $\Phi(t)$ через поверхность, ограниченную этим контуром:

$$\mathcal{E}_i(t) = -\lim_{\Delta t \to 0} \frac{\Delta \Phi}{\Delta t} = -\Phi'(t)$$

Если рамка площади $S$ вращается с угловой скоростью $\omega$ в однородном поле $B$, то $\Phi(t) = B S \cos(\omega t)$. Тогда:

$$\mathcal{E}_i(t) = -(B S \cos(\omega t))' = B S \omega \sin(\omega t) \implies \mathcal{E}_{\max} = B S \omega$$

Задачи на экстремум (Оптимизация параметров)

Доказательство максимума полезной мощности источника:

Полезная мощность, выделяемая на нагрузке с сопротивлением $R$, подключенной к источнику с ЭДС $\mathcal{E}$ и внутренним сопротивлением $r$, равна:

$$P(R) = I^2 R = \left( \frac{\mathcal{E}}{R + r} \right)^2 R = \frac{\mathcal{E}^2 R}{(R + r)^2}$$

Найдем сопротивление $R$, при котором мощность максимальна. Для этого приравняем производную $P'(R)$ к нулю по правилу дифференцирования дроби $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$:

$$P'(R) = \mathcal{E}^2 \cdot \frac{1 \cdot (R + r)^2 - R \cdot 2(R + r)}{(R + r)^4} = \mathcal{E}^2 \cdot \frac{(R + r) - 2R}{(R + r)^3} = \mathcal{E}^2 \cdot \frac{r - R}{(R + r)^3} = 0$$

Дробь равна нулю, когда числитель равен нулю: $r - R = 0 \implies \mathbf{R = r}$.

Таким образом, максимальная мощность во внешней цепи выделяется тогда, когда сопротивление нагрузки равно внутреннему сопротивлению источника.

Экспресс-разбор типичных заданий ЕГЭ

Пример (Задание №4): Колебания пружинного маятника

Условие: Координата груза на пружине зависит от времени по закону $x(t) = 0{,}04 \cos(5\pi t)$ (где все величины выражены в СИ). Найдите максимальную скорость и максимальное ускорение груза.

Решение:

  1. Сравним уравнение с общим видом $x(t) = x_{\max} \cos(\omega t)$: $$x_{\max} = 0{,}04\text{ м}, \quad \omega = 5\pi\text{ рад/с}$$
  2. Находим скорость как производную координаты: $$v(t) = x'(t) = 0{,}04 \cdot (-5\pi) \sin(5\pi t) = -0{,}2\pi \sin(5\pi t)$$ $$v_{\max} = 0{,}2\pi\text{ м/с} \approx 0{,}628\text{ м/с}$$
  3. Находим ускорение как производную скорости: $$a(t) = v'(t) = -0{,}2\pi \cdot (5\pi) \cos(5\pi t) = -\pi^2 \cos(5\pi t)$$ $$a_{\max} = \pi^2\text{ м/с}^2 \approx 9{,}87\text{ м/с}^2$$

Ответ: $v_{\max} = 0{,}2\pi\text{ м/с}$, $a_{\max} = \pi^2\text{ м/с}^2$.

Пример (Задание №14): ЭДС индукции при нелинейном магнитном потоке

Условие: Магнитный поток через проводящий контур сопротивлением $R = 2\text{ Ом}$ меняется по закону $\Phi(t) = 3t^2 - 4t + 1$ (в СИ). Найдите модуль силы индукционного тока в контуре в момент времени $t = 3\text{ с}$.

Решение:

  1. По закону Фарадея модуль ЭДС индукции равен производной магнитного потока: $$\mathcal{E}_i(t) = |\Phi'(t)| = |(3t^2 - 4t + 1)'| = |6t - 4|$$
  2. Вычисляем ЭДС в момент времени $t = 3\text{ с}$: $$\mathcal{E}_i(3) = |6 \cdot 3 - 4| = 14\text{ В}$$
  3. По закону Ома для полной цепи находим силу тока: $$I = \frac{\mathcal{E}_i}{R} = \frac{14}{2} = 7\text{ А}$$

Ответ: $7\text{ А}$.

Главная ошибка — дифференцирование сложной функции!
При взятии производной от гармонических колебаний часто забывают домножить на циклическую частоту $\omega$ (производную внутренней функции):
  • Ошибка: $(\cos(4t))' = -\sin(4t)$ (неверно!)
  • Правильно: $(\cos(4t))' = -\sin(4t) \cdot (4t)' = -4\sin(4t)$
